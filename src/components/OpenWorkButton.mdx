# OpenWorkButton

A page's Add to Open work: the header's one button with words, outlined and small, "Add to Open work", or "In Open work" with a tick, pressed.

**Seen in** — No story: it is drawn by a topic's, a file's and a team chat's page, which read and write through the relay. Its look is the kit's outlined small **Button** in a **WithTooltip**.

## When

- In **PageHeader**'s `button`, on a page that can be put in Open work: a topic's or a file's page (**useFilePane**) and a team chat's page (**TeamChat**).
- Only where the page can change: none on an archived file or an archived team's chat.

## When not

- In a row's ⋮. A row's menu says it in words, as a **MenuItem** ("Add to Open work", "Remove from Open work").
- On the Desk's Open work itself. Its rows are taken out from their own ⋮.

## How

```tsx
import { useShortcut } from '@estiva-app/ui'
import { OpenWorkButton } from '@/components/OpenWorkButton'
import { useToggleOpenWork } from '@/components/views/useToggleOpenWork'
import { OPEN_WORK_KEY } from '@/lib/openWorkKey'

const openWork = useToggleOpenWork()
const toggle = canChange ? () => openWork.toggle(address) : undefined
useShortcut(OPEN_WORK_KEY, () => toggle?.(), !!toggle)
<PageHeader button={toggle ? <OpenWorkButton inIt={openWork.has(address)} onToggle={toggle} /> : undefined} />
```

- The page binds Ctrl/⌘+O itself. The button's tooltip only names it.

## What it owns

- **The words:** "Add to Open work" and "In Open work", and the tooltip's "Add to Open work" or "Take out of Open work".
- **The look:** outlined and small, the layout icon or a tick, and `aria-pressed` while the page is in Open work.
