# SidePanelButton

The file header's button that shows and hides the third column, the file's
Overview. Pressed while the column is shown.

<Canvas of={SidePanelButtonStories.Shown} />

## When

- In a file's header, on the file page and in the Desk's file pane: the two
  places a file's Overview can open beside its conversation.
- Before the ⋮, after Join or Leave.

## When not

- To close an open thread → the ✕ in **ThreadPanel**'s header. The thread
  takes the column while it is open, whatever this button says.
- A button in any other header → a plain `ToolbarButton` with its own icon
  and tooltip.

## How

```tsx
import { SidePanelButton } from '@/components/SidePanelButton'

const view = useFileView({ … })

<Toolbar aria-label="File actions" surface={false}>
  {view.sidePanel && <SidePanelButton open={view.sidePanel.open} onToggle={view.sidePanel.toggle} />}
</Toolbar>
```

- It is a `ToolbarButton`, so it goes inside the header's `Toolbar`.
- `useFileView` hands back `sidePanel` (from `useSidePanel`) only when the
  column could ever hold something: absent for a read-only file with no card.
- The state is `useSidePanel`'s: closed whenever a file is opened, whatever
  it holds. Opening it holds for that visit only; nothing is remembered.

## What it owns

- **Its words.** "Show side panel" and "Hide side panel", as its tooltip and
  its accessible name, and its pressed state.
