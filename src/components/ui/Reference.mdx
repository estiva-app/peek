# Reference

A `nostr:` reference drawn where it was written: a person, or any object.

**Seen in** — No story: it reads Peek's people directory and the relay. The kit's LinkChip has its stories in the estiva-ui Storybook.

## When

- A person mentioned in a message. An `npub` draws the person from Peek's directory, and a click opens their direct message.
- Any other reference. It draws the kit's LinkChip.

## When not

- To fetch an object. It never resolves anything itself; pass `object`, resolved once for the whole body.
- For a reference inside the box. That is `BoxReference`.

## How

```tsx
import { Reference } from '@/components/ui/Reference'

<Reference uri="nostr:npub1..." urgent={urgentPubkeys} link={false} />
```

- `urgent` is the keys named urgently, which wear the urgent tone. `link={false}` is for an editor: no click, no card.

## What it owns

- **Peek's half:** the person chips from Peek's directory, and the urgent tone from the message's tags.
- **The look and the behaviour of other objects are the kit's LinkChip.** See LinkChip in the estiva-ui Storybook (Links / LinkChip).
