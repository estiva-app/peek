# StatusPill

The status of an item from another app — In Progress, Done, Cancelled — shown
as coloured words.

**Seen in** — no story: it is drawn in a `Reference` chip for another app's
object (a description form's `objectMention`); `Reference.test.tsx` draws it.

## When

- On a foreign object's `Reference` chip that has a `status` slot.

## When not

- For a **topic's** resolved state. That is `TopicState`, which draws a glyph
  Peek owns. This one draws words another app sent.
- On a card, a row or a chip in a message: the kit's link widgets draw a status
  as their mark (`LinkChip`, `LinkRow`, `LinkCard`).
- With a size of your own assumed. It is 12px; **the size is the caller's to
  set** through `className`.

## How

```tsx
import { StatusPill } from '@/components/ui/StatusPill'

<StatusPill slot={object.slots.status} />
<StatusPill slot={ticket.slots.status} className="text-body" />
```

- `slot` is the whole resolved slot, not a string: it carries both the words and
  the colour the owning app chose.

## What it owns

- **The colour map, and its fallback.** Four names — neutral, blue, green,
  muted — and anything unrecognised falls to muted rather than to nothing.
- **Reading the colour the relay sent rather than guessing from the words.** The
  projection sends a label and a colour; it never sends the raw key. A component
  that switched on the words would be guessing at another app's vocabulary.
- **That `muted` means muted.** It used to inherit the surrounding colour, so a
  cancelled item looked ordinary; it maps to `--text-muted` now, which is the
  token that name always meant.

## Props

| | |
| --- | --- |
| `slot` | required — the resolved status slot, with its value and colour |
| `className` | the size is set here |
