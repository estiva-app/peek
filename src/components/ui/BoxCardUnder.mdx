# BoxCardUnder

What goes under a message box, as it will be sent: the one file's card with its
✕, or the live part of each block link, which has no ✕.

<Canvas of={ComposeBoxStories.AnIssueAloneOnItsLine} />

**Seen in** — *Writing & text/Composer/ComposeBox* → **An Issue Alone On Its
Line**, the card under the box with its ✕.

## When

- Under the message box, the reply box and a message's edit box: the three
  boxes `useBoxCard` serves. The rule for what shows is `boxLinksOf`'s, in
  @estiva-app/conversation, read
  from the text the box would send (record a-link-on-words-counts-toward-the-card).

## When not

- Under a sent message → `MessageBody`, which draws the cards the message's
  `embed` tags name, with the author's ✕ on hover.
- A file attached to the message itself → `AttachmentChips`.

## How

```tsx
import { BoxCardUnder } from '@/components/ui/BoxCard'
import { useBoxCard } from '@/components/ui/useBoxCard'

const box = useBoxCard(editor, { here })
<BoxCardUnder box={box} />
// Under an edit box: an edit carries no `part`, so only the card it adds.
<BoxCardUnder box={editBox} parts={false} />
```

## What it owns

- **Nothing when there is nothing.** No card and no part draws no element, so
  the wrapper's `empty:hidden` takes its gap away.
- **The card by its file.** `resolvedObjects` is matched by the file, not the
  spelling of its `naddr`, which may carry relay hints.
- **The order.** The parts first, then the card, as a sent message draws them.
