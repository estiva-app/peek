# GlyphIcon

What a referenced thing is, as a bare icon: a topic, a Ship project or issue,
another app's file, or a message.

<Canvas of={GlyphIconStories.AllGlyphs} />

## When

- Inside a part that brings its own box and takes an icon: a reference chip's
  `icon` (14px, in a sent message and in the composer), a `[` list row's `icon`
  (16px).
- With `referenceGlyph(kind)` or `referenceGlyphOfUri(uri)` from
  `@/lib/fileGlyph` to say which glyph.

## When not

- Before a name in a list or a header, with no box of its own around it. That
  is `TopicState`, which draws the same glyphs in a fixed 16px box so every row
  lines up, and knows a resolved topic, a person and a group too.

## How

```tsx
import { GlyphIcon } from '@/components/ui/GlyphIcon'
import { referenceGlyph } from '@/lib/fileGlyph'

<InlineChip icon={<GlyphIcon glyph={referenceGlyph(object.kind)} />}>…</InlineChip>
```

- `size` is the part's: 14 in a chip, 16 in a list row.
- `className` colours it where the part does not, as a list row's
  `text-text-secondary`.

## What it owns

- **The same icon for the same kind as `TopicState`** — Ship's box for a
  project and list for an issue, the dashed circle for a topic (Katerina,
  7 October). One map, so a chip and the row it was picked from agree.
