# MessageRow

One file's row in place of a line that is only a link to it (SPEC §13.2,
§13.3): the kit's `LinkRow`, drawn from the object the text already read.

**Seen in** — *Writing & text/MessageBody* → **Standalone Reference** (a file)
and **Standalone Message Mention** (a message). In the box being written a lone
link stays its chip (`BoxReference`); the row comes once it is sent.

## When

- A message's line that is only a link to a file or a message, with no card
  under the message standing for it (**MessageBody**).

## When not

- The writer chose a card: **MessageCard**, under the message.
- A link inside a sentence, a person or a Folder: the chip (`MessageChip`; a
  person's is **Reference**).

## How

```tsx
import { MessageRow } from '@/components/ui/MessageLinks'

<MessageRow uri={line.reference} object={resolved[line.reference]} unreadable={line.unreadable} opensAt={line.url} />
```

## What it owns

- **The kit's row.** Peek adds only where a link opens and its count.
- **The comment count**, as a card has it, opening the file's conversation,
  with the unread dot for a member only (Katerina, 30 Oct).
- **The unreadable row.** A reference that names no file draws "not
  available", never an empty row.
- **Where it opens.** `opensAt` is the URL as written; the caller passes it only
  when it names this same file.
