# ForeignObjectSkeleton

The placeholder a card from another app shows while it is read: the card's own
frame, with two bars where the title and its details will be.

**Seen in** — *Messages/ForeignObject/ForeignObjectCard*, Loading, and
*Messages/ForeignObject/PartCard*, Loading.

<Canvas of={ForeignObjectStories.Loading} />

## When

- Under a message, while `ForeignObjectWidget` or `PartCard` waits for the
  relay's answer. Both draw it themselves.

## When not

- A list or a row that is loading → the package's `SkeletonList` or
  `SkeletonRow`.
- An answer that never came → say so in words; a placeholder that never goes
  away reads as "still loading" forever.

## How

```tsx
import { ForeignObjectSkeleton } from '@/components/ui/ForeignObjectWidget'

if (!resolved) return <ForeignObjectSkeleton className="mt-1" />
```

<Canvas of={PartCardStories.Loading} />

## What it owns

- **The card's shape.** The same radius, border, inset fill and padding as the
  card it stands in for, so the swap does not move the message.
- **A short wait before it shows.** It stays invisible for its first 150ms, so
  an answer that comes quickly never flashes a placeholder.
- **Being hidden from assistive technology** while it waits.
