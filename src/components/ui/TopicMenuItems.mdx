# TopicMenuItems

The items of a topic's one menu, without the menu around them: for a row that
draws its own ⋮, as the package's `NavItem` does in the Folders tree.

**Seen in**: *Overlays/Menus*, the tree row story. Point at the row and press its ⋮.

## When

- A part that owns its menu and takes items: `NavItem`'s `menu`.
- The same handlers as **TopicMoreMenu**, and the same rule: an item is drawn
  only when its handler is there.

## When not

- Anywhere that needs the trigger too: that is **TopicMoreMenu**, which draws
  these same items inside its own `Menu`.

## How

```tsx
import { TopicMenuItems } from '@/components/ui/TopicMoreMenu'

<NavItem href={href} label={title} menu={<TopicMenuItems onRename={rename} onDeleteTopic={remove} />} />
```

## What it owns

- **One list of items for both menus.** `TopicMoreMenu` draws exactly these, so a
  row's menu and the header's cannot drift apart.
