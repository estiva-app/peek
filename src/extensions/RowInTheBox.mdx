# RowInTheBox

A line that is only a link, drawn as its row while it is written, as the sent
message will draw it (`loneLinkRows`).

<Canvas of={ConversationBoxStories.AnIssueAloneOnItsLine} />

**Seen in** — *Writing & text/Composer/ConversationBox* → **An Issue Alone On
Its Line**.

## When

- Inside a box, for a reference alone on its line: Peek's mention nodes draw it,
  and **BoxReference** draws it for the package's box.

## When not

- A reference inside a line of text → **BoxReference**'s chip.
- A sent message's row → the package's `LinkRow`, through `MessageBody`.

## How

```tsx
import { RowInTheBox } from '@/extensions/mention'

<RowInTheBox uri={uri} object={resolved[uri]} />
```

## What it owns

- **No way out of the draft**: a click on the row's link is held, as a chip's
  is.
- **No preview**: the row is drawn with `preview={false}` while it is written.
